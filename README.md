# ПРЕДПРИЯТИЕ 3826 — Пульт оператора

Персональный дашборд в стиле Atomic Heart (предприятие «Предприятие 3826»): калькулятор инсулина и хлебных единиц, плитки быстрого запуска, геймифицированные задачи и секретный праздничный протокол.

**Живой сайт (GitHub Pages):** после первого деплоя будет доступен по адресу вида
`https://<ваш-логин>.github.io/predpriyatie-3826/`

## Возможности

- **ХРАЗ-статус-бар** — часы, рандомные системные сводки, текущий ранг, тумблер звука.
- **Модуль «Биометрия и Полимер»** — калькулятор инсулина:
  - база быстрой еды в 1 клик (шаурма, пельмени, пицца, чипсы, кола зеро, энергетик…), свои продукты можно добавлять;
  - ручной ввод в граммах углеводов или в ХЕ (1 ХЕ = 10 или 12 г — настраивается);
  - учёт текущего сахара, коррекция по ФЧИ к целевому уровню;
  - персональные УК на утро/день/вечер (панель настроек под шестерёнкой);
  - блок ГИПО-защиты (сахар < 3.9 — подсказка вместо дозы);
  - вердикт «Ввести: X.X ЕД» с разбивкой (на еду + на снижение);
  - таймер активного инсулина (IOB, распад 4 часа) после отметки «Инъекция выполнена».
- **Быстрый запуск** — плитки YouTube / Twitch / Discord Web / Яндекс Музыка + свои терминалы (по кнопке «+ Добавить терминал»).
- **Оперативные директивы** — задачи с геймификацией: за каждую выполненную +10 полимеров, шкала рангов от «Стажер 3826» до «Майор Нечаева».
- **Секретный протокол «АРХИВ: ДР-16»** — мигающая кнопка в правом нижнем углу, ввод кода (по умолчанию `1608`, меняется в настройках), открывает «Приказ №16» с поздравлением и сертификатом на копию Atomic Heart.
- **Автосохранение** — всё (коэффициенты, еда, задачи, полимеры, плитки, таймеры) лежит в `localStorage` браузера.
- **Экспорт/импорт профиля JSON** — перенос между браузерами и телефоном.
- **Звуковой движок на Web Audio API** — синтезированные щелчки, сканер, звук опыта; отключается одним тумблером. Никаких внешних файлов.

## Запуск

Ничего собирать не нужно — чистые HTML/CSS/JS.

- Локально: просто открыть `index.html` в браузере, либо `python3 -m http.server` и открыть `http://localhost:8000`.
- GitHub Pages: включается автоматически workflow-ом `.github/workflows/deploy-pages.yml` при пуше в `main`.

## Персонализация

1. Нажмите ⚙ в панели калькулятора.
2. Впишите имя оператора, код архива (например, день рождения), свои УК/ФЧИ/цель и размер ХЕ.
3. Текст поздравления в «Приказе №16» меняется в `app.js`, функция `openCertificate()`.

> ⚠ Дашборд помогает считать, но не заменяет врача: УК и ФЧИ подбираются вместе с эндокринологом.
